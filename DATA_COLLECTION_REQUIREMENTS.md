# Mahrea — Data Collection Requirements

**Purpose:** Complete checklist of everything that must be collected from the Mahrea team before and during development.  
**Version:** 1.0 | June 2026

> Delays in providing any item marked **CRITICAL** will directly block development and delay the launch date.

---

## STATUS LEGEND
- 🔴 CRITICAL — Blocks development. Must have before work begins.
- 🟡 IMPORTANT — Needed before launch. Can be provided mid-development.
- 🟢 OPTIONAL — Nice to have. Can be added post-launch.

## 4. Product Data

**Required for every product before development of category pages and PDP can begin.**

| Field | Detail Required | Priority | Received |
|---|---|---|---|
| Product Name | Full product name as it should appear on website | 🔴 CRITICAL | ☐ |
| Category | Which of the 6 categories it belongs to | 🔴 CRITICAL | ☐ |
| SKU | Unique product code (can be alphanumeric) | 🔴 CRITICAL | ☐ |
| Selling Price (₹) | Final customer price in INR (inclusive of all charges) | 🔴 CRITICAL | ☐ |
| Original Price (₹) | If showing a "was ₹X" strikethrough (optional) | 🟢 OPTIONAL | ☐ |
| Metal Type | Gold / Silver / Platinum / Rose Gold / Brass | 🔴 CRITICAL | ☐ |
| Metal Colour | Yellow Gold / White Gold / Rose Gold / Rhodium-plated / Oxidised | 🔴 CRITICAL | ☐ |
| Purity | 22KT / 18KT / 925 Sterling / etc. | 🟡 IMPORTANT | ☐ |
| Stone Type | Diamond / Ruby / Emerald / Pearl / CZ / None | 🟡 IMPORTANT | ☐ |
| Weight (grams) | Product weight | 🟡 IMPORTANT | ☐ |
| Product Description | 50–150 words describing the piece, its design, occasion | 🔴 CRITICAL | ☐ |
| Product Images | Minimum 3 angles per product: front, back/side, lifestyle | 🔴 CRITICAL | ☐ |
| Product Image Resolution | Minimum 800×800px. 1000×1000px or higher preferred | 🔴 CRITICAL | ☐ |
| Stock Quantity | Opening inventory count | 🔴 CRITICAL | ☐ |
| Size Options | For rings: size range (e.g., 5–18). For bracelets: S/M/L or cm | 🟡 IMPORTANT | ☐ |
| Care Instructions | How to clean/store (can be category-level template) | 🟢 OPTIONAL | ☐ |
| Hallmark Certified | Yes / No — BIS hallmark | 🟡 IMPORTANT | ☐ |
| Product Tags | Keywords for search + mood/collection tagging | 🟢 OPTIONAL | ☐ |
| Is Featured | Should it appear in "New Arrivals" or "Trending"? | 🟡 IMPORTANT | ☐ |

> **Recommended data format:** Provide product data in a Google Sheet with one product per row and one column per field. A template will be shared separately.
